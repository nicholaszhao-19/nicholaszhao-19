## Featured research

### Ancilla-efficient QSample preparation

[Repository](https://github.com/nicholaszhao-19/ancilla-efficient-qsample) · [Paper](https://arxiv.org/abs/2605.23442)

Solo-authored paper accepted at **IEEE QCE 2026 (QALG track)**. The repository contains a deterministic spectral reference experiment on a **2 × 4 Ising ladder**, saved numerical results, mathematical specifications and a validation suite. The backend is a numerical reference, not a gate-level or quantum-hardware experiment.

### TTC OperatorBench

[Repository](https://github.com/nicholaszhao-19/ttc-operatorbench)

A reproducible evaluation harness for verifier-guided code generation under test-time compute budgets, with recorded experiments and explicit evidence limits.
