# Nicholas Zhao

PhD researcher in Electrical and Electronic Engineering at **Imperial College London**, supervised by Professor Cong Ling. Expected completion: **January 2027**.

I work on **quantum algorithms for sampling**, with interests in quantum walks, quantum signal processing and lattice cryptography.

## Selected work

- **[Ancilla-Efficient QSAMPLE Preparation for Reversible Markov Chains](https://arxiv.org/abs/2605.23442)**: solo-authored paper, IEEE QCE 2026 (QALG track). Numerical experiments, tests and audit: [ancilla-efficient-qsample](https://github.com/nicholaszhao-19/ancilla-efficient-qsample).
- **[ttc-operatorbench](https://github.com/nicholaszhao-19/ttc-operatorbench)**: a reproducible evaluation harness for verifier-guided code generation under test-time compute budgets, with hash-verified results.
